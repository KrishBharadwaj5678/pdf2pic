<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/pdf2pic.png" width="45"/> PDF2PIC</h1>

<p align="center">
  PDF2PICは、PythonとStreamlitをベースにしたユーティリティです。PDFファイルに埋め込まれた画像を抽出し、ダウンロードしやすいZIPアーカイブにまとめることができます。
</p>

<img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 🖼️ 高品質な画像抽出 | 画像の鮮明さや重要な視覚的ディテールを維持したまま抽出します |
| 🗜️ ZIPパッケージ | 複数の画像を1つのZIPファイルにまとめてダウンロードできます |
| 🌐 Streamlitインターフェース | ブラウザから利用できる高速で使いやすいWebインターフェースを提供します |
| ⚡ 軽量＆高速 | 最小限のリソースで動作するよう最適化されています |

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/pdf2pic.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd pdf2pic
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash
streamlit run app.py
```
