<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/pdf2pic.png" width="45"/> PDF2PIC</h1>

<p align="center">
  O PDF2PIC é uma ferramenta baseada em Python e Streamlit que extrai imagens incorporadas de arquivos PDF e as reúne em um conveniente arquivo ZIP para download.
</p>

<img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| ------- | --------- |
| 🖼️ Extração de alta qualidade | Preserva a nitidez das imagens e detalhes visuais importantes |
| 🗜️ Compactação em ZIP | Permite baixar várias imagens reunidas em um único arquivo ZIP |
| 🌐 Interface Streamlit | Interface web rápida e fácil de usar, acessível pelo navegador |
| ⚡ Leve e rápido | Desempenho otimizado com uso mínimo de recursos |

<img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/techStack.gif" width="35"/> Tecnologias Utilizadas

| Tecnologia | Finalidade |
| ---------- | ---------- |
| <img src="https://skillicons.dev/icons?i=python" width="25"/> **Python** | Lógica principal e processamento do backend |
| <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/streamlit.png" width="25"/> **Streamlit** | Fornece uma interface web rápida e interativa |
| <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/fitz.png" width="25"/> **Fitz (PyMuPDF)** | Extrai e processa imagens de arquivos PDF |
| <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/zipfile.png" width="35"/> **Zipfile** | Reúne as imagens extraídas em um arquivo ZIP para download |

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/pdf2pic.git
````

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd pdf2pic
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar o Aplicativo

```bash
streamlit run app.py
```
