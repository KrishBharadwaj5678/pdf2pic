<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/pdf2pic.png" width="45"/> PDF2PIC</h1>

<p align="center">
  PDF2PIC это утилита на основе Python и Streamlit, которая извлекает встроенные изображения из PDF-файлов и объединяет их в удобный ZIP-архив для скачивания.
</p>

<img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ----------- | -------- |
| 🖼️ Извлечение в высоком качестве | Сохраняет чёткость изображений и важные визуальные детали |
| 🗜️ Упаковка в ZIP | Позволяет скачать несколько изображений в одном ZIP-архиве |
| 🌐 Интерфейс Streamlit | Быстрый и удобный веб-интерфейс, доступный через браузер |
| ⚡ Лёгкость и высокая скорость | Оптимизированная производительность при минимальном использовании ресурсов |

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
 git clone https://github.com/KrishBharadwaj5678/pdf2pic.git
````

### 2️⃣ Переход в директорию проекта

```bash
 cd pdf2pic
```

### 3️⃣ Установка зависимостей

```bash
 pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
 streamlit run app.py
```
