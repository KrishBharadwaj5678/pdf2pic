<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/pdf2pic.png" width="45"/> PDF2PIC</h1>

<p align="center">
  PDF2PIC is a Python and Streamlit-based utility that extracts embedded images from PDF files and bundles them into a convenient downloadable ZIP archive.
</p>

<img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                    | Description                                           |
| -------------------------- | ----------------------------------------------------- |
| 🖼️ High-Quality Extraction | Preserves image clarity and important visual details  |
| 🗜️ ZIP Packaging           | Download multiple images bundled in a single ZIP file |
| 🌐 Streamlit Interface    | Fast and user-friendly web UI accessible in a browser |
| ⚡ Lightweight & Fast     | Optimized performance with minimal resources required |

<img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/techStack.gif" width="35"/> Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| <img src="https://skillicons.dev/icons?i=python" width="25"/> **Python** | Core scripting and backend logic |
| <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/streamlit.png" width="25"/> **Streamlit** | Provides a fast and interactive web interface |
| <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/fitz.png" width="25"/> **Fitz (PyMuPDF)** | Extracts and processes images from PDF files |
| <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/icons/zipfile.png" width="35"/> **Zipfile** | Bundles extracted images into a downloadable ZIP |

## <img src="https://github.com/KrishBharadwaj5678/pdf2pic/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
 git clone https://github.com/KrishBharadwaj5678/pdf2pic.git
```

### 2️⃣ Navigate to the Project

```bash
 cd pdf2pic
```

### 3️⃣ Install dependencies 

```bash
 pip install -r requirements.txt
```

### 4️⃣ Run the app

```bash
 streamlit run app.py
```
